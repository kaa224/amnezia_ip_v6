# 9. Лицензии и распространение

Лицензия собственных текстов/шаблонов/скриптов этого проекта пока **не назначена** владельцем. Отсутствие LICENSE не означает public domain или автоматическое разрешение свободного переиспользования. До публикации как распространяемого пакета владельцу нужно выбрать лицензию.

Upstream остается под своими условиями:

| Компонент | Условия |
|---|---|
| [AWG Go LICENSE](https://github.com/amnezia-vpn/amneziawg-go/blob/v3.1.20261116/LICENSE) | MIT; сохранять copyright/permission notice при копировании существенных частей |
| [Realm LICENSE](https://github.com/zhboner/realm/blob/v2.9.6/LICENSE) | MIT; те же требования к уведомлениям |
| [AWG tools COPYING](https://github.com/amnezia-vpn/amneziawg-tools/blob/v3.1.20260812/COPYING) | В составе GPL-2.0 и файлы с отдельными SPDX (в том числе MIT); проверять файл и состав распространяемой сборки |
| [AmneziaVPN LICENSE](https://github.com/amnezia-vpn/amnezia-client/blob/5.1.1.10/LICENSE) | GPL-3.0, см. также THIRD_PARTY_LICENSES.md; проверять bundled dependencies перед распространением приложения |

Здесь upstream бинарники, исходные файлы, install scripts и полные конфигурации стороннего проекта не перепаковываются. Примеры написаны для документации, а параметры API сверены с исходниками. Сборка для личного использования и распространение бинарников — разные действия: при распространении tools с GPL соблюдать условия по исходникам и уведомлениям, не заменять их лицензией этого репозитория. Go modules/Rust crates и toolchain имеют дополнительные собственные лицензии; сохраните их при создании дистрибутива. Этот текст не назначает владельцу обязательства за upstream и не заменяет проверку лицензий конкретного артефакта.
