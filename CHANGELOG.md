# Изменения

## 2026-11-20 — запуск после reboot

- Добавлена диагностика `226/NAMESPACE` при отсутствующем `/run/xtables.lock`: постоянное создание через tmpfiles, порядок запуска systemd, сохранение общего IPC-каталога и проверки после reboot. Уточнено, какие адаптированные units затронуты; сетевые шаблоны и политика SSH не менялись.

## 2026-11-20 — воспроизводимое руководство

- README превращен в оглавление и безопасный быстрый старт; предыдущая версия сохранена в Git по base SHA.
- Добавлены требования, provider-specific подготовка IPv6, pinned upstream и ручной порядок развертывания.
- Добавлены документированные AWG/Realm, systemd и additive firewall templates, только документационные адреса.
- Добавлены выдача/отзыв отдельных профилей, Windows/iOS проверки, диагностика local INPUT HTTPS, обслуживание и rollback.
- Добавлены локальные validator/prepare и tests без изменений сети/production.
- Отделены исторические результаты от непроведенных чистых стендовых испытаний; собственная лицензия не назначена.
