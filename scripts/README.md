# Локальные инструменты

Python 3.11+ (нужен стандартный `tomllib`), без pip и сторонних зависимостей.

- `python3 scripts/prepare.py /existing-parent/new-private-directory`: создает новый каталог 0700 **вне checkout**, копии examples/systemd 0600. Отказывается перезаписывать существующий каталог. Не подставляет значения, не генерирует секреты, не устанавливает компоненты. После прерванной операции может остаться частичная копия — проверьте и удалите ее вручную перед повтором.
- `python3 scripts/validate.py`: проверяет **только шаблоны репозитория**, JSON/TOML/INI, структуру additive rules, адресные диапазоны inventory, синтаксис Python и локальные Markdown-ссылки. Не направляйте его на закрытые рабочие конфиги. Проверка конфигураций с повторными `[Peer]` структурная: semantic parse реальных значений обязан сделать официальный `awg` на закрытом стенде.
- `python3 -m unittest discover -s tests -v`: проверка ограничений, правил, prepare и отказов. Файлы создаются только в локальном временном каталоге.

Ни один скрипт не вызывает SSH, curl, ip, iptables, systemctl или другие процессы, не создает network namespace, не использует сокеты. В `systemd/` находятся отдельно **ручные шаблоны для последующей установки администратором**, а не действия этих скриптов.

Код не является secret scanner общего назначения: аудит diff, исторических данных и собственных подставленных значений требуется отдельно. Ошибки валидатора не показывают входные строки, чтобы не размножать случайно попавшие в файл секреты.
